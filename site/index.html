Znote

Push-to-talk voice-to-text. Instant translation. Native macOS menu bar.

100% on-device · No cloud · No subscription · Apple Silicon optimized

Download for macOS v0.6.0 · Apple Silicon View on GitHub

Requires macOS 14 or later

What it does

🎙

Voice → Text

Hold Right ⌘, speak, release. Text is pasted at your cursor wherever you are — Slack, mail, code, anywhere.

WhisperKit (CoreML) · runs on Apple Neural Engine

🌐

Translate selection

Select any text in any app, tap Right ⌥. A floating overlay shows the translation. One click copies it.

Auto-detect language · Chinese ↔ English

📜

History

Every transcription and translation is saved locally. Search, filter by date, expand long entries, copy or delete.

SQLite · stored in ~/Library/Application Support/Znote/

📸

Screenshot

Double-tap Right ⌥ to trigger macOS region screenshot — straight to clipboard, ready to paste.

Uses native screencapture

Default hotkeys

GestureAction
Right ⌘ holdVoice → Text (push-to-talk)
Right ⌘ tapToggle History window
Right ⌥ tapTranslate selected text
Right ⌥ double-tapScreenshot to clipboard

Every hotkey is customizable in Settings — pick any side (Left/Right) + modifier (⌘/⌥/⌃). Tap actions can be swapped to double-tap and vice versa.

Install

  1. Download Znote.dmg from latest release, double-click to mount, drag Znote.app to Applications.
  2. Launch from Spotlight or /Applications/Znote.app. A waveform icon appears in your menu bar.
  3. Grant three permissions in System Settings → Privacy & Security:
    • Microphone — for voice recording
    • Accessibility — for clipboard Cmd+C/V simulation
    • Input Monitoring — for detecting Right ⌘ / Right ⌥ hotkeys
  4. On first transcription, the Whisper model downloads (~1.6 GB for Turbo, ~3 GB for Large V3). One-time, then cached.

Models

Large V3 ~3 GB

Best quality · multilingual (99 languages) · proper punctuation · ~1× realtime.

Large V3 Turbo ~1.6 GB

~8× faster than Large V3 · multilingual · weaker punctuation. Great for low-latency dictation.

Small ~500 MB

Lightweight · English-mainly · Chinese accuracy noticeably degraded. Pick when disk space is tight.
